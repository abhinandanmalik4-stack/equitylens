# EquityLens — AI Stock Research Assistant

EquityLens is a planned stock research website that brings price charts, company information, and machine learning forecasts into one place. It aims to help users explore how a stock has performed, understand the business behind it, and ask company questions through an AI assistant that cites reliable sources.

## Planned features

- **Stock search and watchlist:** Find companies and keep track of selected stocks from a left sidebar.
- **Interactive price charts:** Explore the latest available price, daily change, trading volume, and historical performance across different time periods.
- **Historical comparisons:** Compare previous closing prices and performance over months and years.
- **Evaluated forecasts:** Explore machine learning forecasts with uncertainty estimates, measured against a simple baseline using chronological evaluation.
- **Company research chatbot:** Ask about company history, how the business developed, financial results, risks, and future outlook, with answers grounded in reliable company documents and cited sources.

Price values will come from stock-data tools. Forecast values will come from evaluated models, rather than numbers generated by the chatbot.

## Initial scope and approach

The proposed first version focuses on one Indian exchange, 10–20 stocks, historical daily prices, company question answering, and one forecasting model. US stocks are future scope. The exact exchange and data provider are still to be decided.

The accepted first-version direction is Python with Streamlit for the interface, Plotly for charts, pandas/NumPy for data processing, SQLite for persistence, and scikit-learn for model evaluation. No handwritten HTML, CSS or JavaScript is needed. A separate FastAPI service can be added later if useful. The planned retrieval-augmented chatbot will find relevant passages in reliable documents before answering. The model pipeline will clean data, generate features, evaluate on chronological splits without data leakage, and report prediction errors and uncertainty.

Data availability, refresh frequency, and display rights will depend on the selected provider.

## Project status

**Planning stage — application implementation has not started.** The features above describe the intended direction, not functionality currently available.

EquityLens is being developed as a final-year computer science engineering project to build practical skills in full-stack development, data engineering, machine learning, and AI applications. The intended outcome is a working demo with clear architecture, reproducible evaluation, baseline comparisons, and useful documentation.
