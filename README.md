# EquityLens — AI Stock Research Assistant

EquityLens is a Python-first stock research project. Its local dashboard supports synthetic demo prices and user-supplied historical CSV files labelled unverified. Direct market-provider integration, evaluated forecasts and cited company Q&A are upcoming milestones.

## Run the local demo

Requires Python; 3.13 is the tested version. From this checkout:

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-lock.txt -e .
.venv\Scripts\python.exe -m streamlit run app.py --server.address 127.0.0.1
```

The environment is already set up on the current development machine. Open the Local URL printed by Streamlit. [Setup, checks and guided walkthrough](docs/RUN_AND_LEARN.md).

## Available in milestone 1

- Search a ten-company Indian demo catalogue.
- Explore line/candlestick charts, volume and observation-range price changes.
- Compare synthetic paths on matching dates with a common starting value of 100.
- Save a local single-user SQLite watchlist across restarts.
- Inspect/download labelled synthetic observations with source metadata.
- Import bounded single-company OHLCV CSVs with explicit source and adjustment declarations.
- Choose inclusive calendar windows, view historical return horizons and close-based drawdown, and inspect files offline.

**Built-in demo prices and volumes are invented**, fixed through October 23, 2026. Uploads stay unverified and never silently fall back to demo prices. The included example file is also invented. [CSV workflow and limitations](docs/CSV_IMPORT_GUIDE.md). Research and forecast panels do not generate answers or predictions yet.

## Planned features

- **Stock search and watchlist:** Find companies and keep track of selected stocks from a left sidebar.
- **Interactive price charts:** Explore the latest available price, daily change, trading volume, and historical performance across different time periods.
- **Historical comparisons:** Compare previous closing prices and performance over months and years.
- **Evaluated forecasts:** Explore machine learning forecasts with uncertainty estimates, measured against a simple baseline using chronological evaluation.
- **Company research chatbot:** Ask about company history, how the business developed, financial results, risks, and future outlook, with answers grounded in reliable company documents and cited sources.

Price values will come from stock-data tools. Forecast values will come from evaluated models, rather than numbers generated by the chatbot.

## Initial scope and approach

The proposed first version focuses on one Indian exchange, 10–20 stocks, historical daily prices, company question answering, and one forecasting model. US stocks are future scope. The exact exchange and data provider are still to be decided.

The accepted first-version direction is Python with Streamlit for the interface, Plotly for charts, pandas/NumPy for data processing, SQLite for persistence, and scikit-learn for model evaluation. No handwritten HTML, CSS or JavaScript is needed. A separate FastAPI service can be added later if useful. The planned retrieval-augmented chatbot will find relevant passages in reliable documents before answering. The model pipeline will clean data, generate features, evaluate on chronological splits without data leakage, and report prediction errors and uncertainty.

Data availability, refresh frequency, and display rights will depend on the selected provider.

## Project status

**October 27, 2026: local dashboard and CSV workflow implemented.** Direct real-data-provider integration, trained/evaluated models, document retrieval, AI chat, authentication and deployment are not implemented. Remaining planned features describe the intended direction, not available functionality.

Validation, updated October 28: 41 local automated tests pass for catalogue, data contracts, numeric boundaries, CSV import/export, calendar windows, historical statistics, offline inspection, figures, watchlist persistence and Streamlit interactions. Nonrepresentable returns are explicitly unavailable, not infinite scores. Remote Windows/Linux checks must be checked separately; browser layout and gestures are not visually verified.

EquityLens is being developed as a final-year computer science engineering project to build practical skills in full-stack development, data engineering, machine learning, and AI applications. The intended outcome is a working demo with clear architecture, reproducible evaluation, baseline comparisons, and useful documentation.
